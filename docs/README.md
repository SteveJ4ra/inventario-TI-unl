# Documentación del proyecto

Este directorio contiene la documentación relacionada con el análisis, las decisiones y el desarrollo del proyecto **Inventario de Tecnologías de Información**, realizado por el grupo N * * de la carrera de Computación - 5to Ciclo.

## Organización de la documentación

La documentación se incorporará progresivamente conforme avance el proyecto, incluyendo:

- Análisis del problema, alcance y restricciones.
- Identificación de actores y sus necesidades.
- Fundamentos y aplicación de Spec-Driven Development (SDD).
- Análisis y justificación de las tecnologías seleccionadas.
- Decisiones técnicas y documentación complementaria.

Los artefactos de GitHub Spec Kit se organizarán según la estructura definida para dicha herramienta.

## Consideraciones

- La documentación debe mantenerse actualizada conforme evolucione el proyecto.
- Los cambios deben registrarse mediante Git para conservar su trazabilidad.
- Evitar subir claves secretas del proyecto
