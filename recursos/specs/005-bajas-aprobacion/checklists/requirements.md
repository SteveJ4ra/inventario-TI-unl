# Checklist: requisitos 005

- [x] Baja normal y baja aprobada se distinguen.
- [x] Motivo, autor y fecha quedan registrados.
- [x] No localizado no se da de baja sin decisión independiente.
- [x] Reviewer es de otra facultad y no puede editar inventario.
- [x] Rechazo permite solicitud nueva con motivo actualizado.
- [x] Recuperación cancela pending con motivo y referencia.
- [x] Reviewer no se desactiva con pendientes sin reasignar.
- [x] Contraseña temporal requiere cambio al primer acceso.
- [x] Baja errónea conserva antecedente y solo se rectifica como evento más reciente.
- [x] Roles técnicos no se presentan como cargos institucionales.
