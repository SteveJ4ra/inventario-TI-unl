# Contratos web: bajas y aprobación

- Gestor ve acción Baja normal solo para activo elegible; la acción pide motivo.
- Para No localizado, Gestor crea solicitud con motivo y selecciona revisor de facultad distinta; solo se muestran revisores activos y elegibles.
- Revisor inicia sesión con contraseña temporal y debe cambiarla antes de acceder.
- Bandeja de reviewer contiene únicamente solicitudes asignadas; ficha contextual de solo lectura.
- Aprobar confirma la baja; rechazar exige motivo.
- Después de rechazo, Gestor puede crear solicitud nueva con motivo actualizado.
- Si hay recuperación antes de decidir, solicitud aparece Cancelada, motivo Activo recuperado; no se ofrece aprobación.
- Operador crea y desactiva revisores, asigna facultad y reasigna solicitudes pendientes antes de desactivar.
- Gestores se dan de alta/baja por comando; no hay UI pública de gestores.
