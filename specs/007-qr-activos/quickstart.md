# Quickstart: QR

1. Configurar `PUBLIC_APP_URL` con la URL HTTPS canónica del entorno.
2. Instalar la versión fijada de Segno cuando se implemente.
3. Iniciar backend y frontend conforme a quickstart de 002.
4. Iniciar sesión como Gestor, abrir un activo y descargar SVG.
5. Escanearlo sin sesión: se solicita login; completar autenticación y comprobar que abre la ficha correcta.
6. Repetir con código inexistente y cuenta sin permiso; comprobar que no se revela ficha.

Este procedimiento describe aceptación futura; no se ha ejecutado.
